# Artwork in this folder

The files here are not covered by the GPL license of this package. Each has its own terms.

Every picture is shown in the app with a label saying it is AI-generated. We will replace each one as soon as someone
gives us artwork made by a person that we can legally use. To offer a piece, start a thread in Discussions on the
GitHub repository, or open an issue there.

The game pictures below were made with DeviantArt DreamUp. Each entry reads: "Made by the Salvage Rights team with an
AI image tool (DeviantArt DreamUp) on or before 2026-11-25, cropped and resized. Prompt: not recorded." We will add
the prompts when we have them.
